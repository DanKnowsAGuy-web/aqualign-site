# AquAlign — Relaunch Website

Marketing site for AquAlign Systems Inc. (formerly TE AquAlign Systems): in-line water conditioning for agriculture.

Static site, no build step: `index.html`, `results.html`, `technology.html`, `about.html`, `contact.html` + `styles.css` + `main.js`.

Local preview: `python -m http.server 5173` and open http://localhost:5173.

Content sourced from the recovered te-aqualign.com archive (2013–2020) per the approved brand & messaging foundation. Contact form is UI-only pending a form endpoint.
